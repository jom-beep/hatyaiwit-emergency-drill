      ติดตั้งแอปบนมือถือ

      ทำตามเครื่องของคุณให้ครบ แล้วเปิดจากไอคอนบนหน้าจอหลัก — อย่าเปิดค้างในเบราว์เซอร์

      1. เปิดด้วย Safari เท่านั้น — Chrome หรือ LINE บน iPhone ติดตั้งแล้วรับแจ้งเตือนไม่ได้
      2. กดปุ่ม แชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบล่างของจอ
      3. เลื่อนลงแล้วเลือก เพิ่มลงหน้าจอโฮม
      4. กด เพิ่ม ที่มุมขวาบน
      5. ออกจาก Safari แล้วเปิดจากไอคอนใหม่บนหน้าจอโฮม
      6. ในแอปที่ติดตั้งแล้ว กด เปิดการแจ้งเตือนเครื่องนี้ แล้วกดอนุญาต
      1. เปิดด้วย Chrome
      2. ถ้ามีแถบ “ติดตั้งแอป” ให้กดติดตั้งเลย
      3. หรือกดเมนู ⋮ มุมขวาบน แล้วเลือก เพิ่มลงในหน้าจอหลัก
      4. กด ติดตั้ง หรือ เพิ่ม เพื่อยืนยัน
      5. เปิดจากไอคอนใหม่บนหน้าจอหลัก
      6. กด เปิดการแจ้งเตือนเครื่องนี้ แล้วกดอนุญาตเมื่อระบบถาม

      ถ้าเปิดผ่านเบราว์เซอร์โดยไม่ติดตั้งเป็นแอป เครื่อง iPhone/iPad จะไม่รับการแจ้งเตือนเมื่อปิดหน้าจอ
